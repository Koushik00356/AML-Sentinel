## Sentinel

An agentic investigation assistant for anti-money-laundering analysts.
The agent builds an execution plan,runs only the analyses that question needs, flags suspicious activity,explains each flag, and recommends an escalation action.

## Problem statement
Rule-based AML systems generate excessive false positives while
sophisticated typologies — structuring, smurfing, layering — evade
detection. This project builds a query-driven agent that detects
laundering patterns and produces explainable, actionable risk assessments.
